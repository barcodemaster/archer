# 구름 효과 시스템 (Cloud System)

## 개요
스카이박스 영역(맵 바깥)에서만 보이는 구름 효과 시스템.
구름을 맵 아래(Y=-2)에 배치하여 맵 타일의 depth buffer로 자동 가림 처리.
플레이어와 독립적으로 drift하며, 카메라 기준 wrap으로 항상 시야 내 존재.

## 핵심 원리
```
카메라(Y=22) ──45°──→ 맵타일(Y=0) ──depth──→ 구름(Y=-2)
                       [opaque, queue 2000]    [transparent, queue 3000]

맵 영역: 맵 타일이 depth buffer를 차지 → 구름 ZTest 실패 → 안 보임
스카이박스 영역: depth buffer 비어있음 → 구름 ZTest 통과 → 보임
```

## 구조

### CloudController (`Assets/Scripts/Environment/CloudController.cs`)
- **Quad 메시 기반**: `CreatePrimitive(Quad)` + `Sprites/Default` 셰이더
  - SpriteRenderer 대신 MeshRenderer 사용 — 3D depth에서 자연스러운 렌더링
  - XZ 평면에 눕힘 (`Rotation X=90`) — 탑다운 카메라에서 평면으로 보임
  - `renderQueue = 3000` (Transparent) + ZTest LEqual → 맵 타일 뒤에서 자동 가림
- **독립 Drift**: 플레이어 추종 없이 순수 drift만 적용 → 자연스러운 구름 이동
- **카메라 기준 Wrap**: 카메라 XZ 위치에서 `wrapDistance` 밖으로 나가면 반대편에서 재등장
- **파티클 보조**: CloudNoise 텍스처 파티클이 분위기 보조 (Y=-2 동일 배치)

### 주요 파라미터 (프리팹 직렬화 값)
| 파라미터 | 값 | 설명 |
|---------|-----|------|
| cloudY | -2 | 맵 바닥(Y=0)보다 약간 아래 → depth 기반 자동 가림 |
| wrapDistance | 40 | 카메라 기준 구름 분포 범위 (넓은 시야 커버) |
| cloudCount | 10 | 구름 개수 |
| scaleRange | 8~16 | 구름 크기 범위 (Y=-2 가까워져 스케일 축소) |
| alphaRange | 0.2~0.4 | 투명도 범위 (가까워져 알파 약간 낮춤) |
| driftSpeed | 2.0 | 기본 이동 속도 (화면상 체감 가능) |

## 설계 결정 과정

### SpriteRenderer → Quad+MeshRenderer 전환
- **문제**: SpriteRenderer는 3D 깊이(depth test)에서 정상 동작하지 않음
  - `sortingOrder`로는 3D 오브젝트와의 depth 관계 제어 불가
- **해결**: `Quad` primitive + `Sprites/Default` 셰이더
  - 3D depth buffer에 참여하여 자연스러운 가림 처리
  - `renderQueue=3000`으로 Transparent 패스에서 렌더링

### 전용 카메라 방식 폐기
- 초기에 Cloud 레이어 + 전용 카메라(`depth = mainCam.depth - 1`) 시도
- **문제**: 메인 카메라의 Skybox clearFlags가 구름 카메라 렌더링을 덮어씀
- **결론**: 단일 카메라에서 depth 기반 렌더링이 더 단순하고 효과적

### cloudY = -2 (맵 아래 배치) — v3 수정
- **v1**: cloudY=0.3 → 맵 위에서도 구름이 보여 게임플레이 방해
- **v2**: cloudY=-10 → depth 기반 가림은 작동하나, 48° 하방 카메라에서 맵 타일에 거의 전부 가려져 구름이 안 보임
  - Y=-10까지의 시선이 맵 영역을 거의 다 통과 → 맵 바깥에서 보이는 영역이 화면 가장자리 극소 영역뿐
- **v3**: cloudY=-2 → Y=0 맵 타일보다 약간 아래로 depth 가림 유지하면서, 카메라 시선과의 각도 차이가 작아 맵 바깥 가시 영역이 훨씬 넓어짐
  - scaleRange (10~22 → 8~16), alphaRange (0.25~0.5 → 0.2~0.4) 가까워진 거리에 맞게 축소
  - driftSpeed (0.5 → 2.0) 화면상 이동이 체감되도록 4배 증가

### FollowPlayer 제거 → 카메라 기준 wrap — v2 수정
- **이전(v1)**: `FollowPlayer()`가 CloudSystem을 플레이어 쪽으로 Lerp → 구름이 플레이어 따라감
- **현재(v2)**: CloudSystem 위치 고정, 각 구름이 카메라 XZ 기준으로 wrap
  - 플레이어가 어디로 이동해도 구름은 순수 drift만
  - 카메라 시야 밖으로 나간 구름은 반대편에서 재등장
