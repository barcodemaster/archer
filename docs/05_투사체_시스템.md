# 05. 투사체 시스템

## 개요

`ProjectileBase`가 3가지 이동 타입(Straight, Arc, Piercing)을 지원하며, 벽 반사, 리코셰, 헤드샷, 크리티컬 등 다양한 피격 판정을 통합 처리합니다.

---

## ProjectileInitData 구조체

> `Assets/Scripts/Upgrade/ProjectileInitData.cs`

```csharp
public struct ProjectileInitData
{
    public float damage;
    public bool isPiercing;       // 관통 여부
    public float headshotChance;  // 즉사 확률
    public bool wallBounce;       // 벽 반사 활성화
    public int ricochetCount;     // 리코셰 남은 횟수
    public float ricochetRadius;  // 리코셰 탐색 반경
    public float critChance;      // 크리티컬 확률
    public float critDamageMin;   // 크리티컬 최소 배율
    public float critDamageMax;   // 크리티컬 최대 배율
}
```

### 설계 의도

> **왜 struct인가?** `ProjectileInitData`는 매 공격마다, 방향 수 × FrontArrow 수만큼 생성된다. 멀티샷과 모든 방향 업그레이드가 활성화되면 **한 번 공격에 수십 개**가 만들어진다. class로 선언하면 매번 힙 할당 + GC 대상이 되어 프레임 스파이크를 유발할 수 있다. struct는 스택에 할당되므로 **GC 압박 없이 대량 생성/소멸이 가능**하다.

- **구조체(struct)** 사용: GC 부담 없이 스택 할당
- PlayerController.SpawnVolley()에서 구성 → ProjectileBase.Init()에 전달

## ProjectileBase - 통합 투사체

> `Assets/Scripts/Projectile/ProjectileBase.cs`

```csharp
public class ProjectileBase : MonoBehaviour
{
    [Header("Common")]
    [SerializeField] private float _speed = 10f;
    [SerializeField] private float _lifeTime = 3f;
    [SerializeField] private float _knockbackForce = 0f;
    [SerializeField] private bool _isPlayerProjectile;
    [SerializeField] private EProjectileMoveType _moveType = EProjectileMoveType.Straight;

    [Header("Bounce Option")]
    [SerializeField] private bool _bounceEnabled;
    [SerializeField] private int _maxBounces = 5;
    [SerializeField] private float _bounceRadius = 0.2f;

    [Header("Arc Option")]
    [SerializeField] private float _arcHeight = 3f;
    [SerializeField] private float _arcDuration = 0.8f;

    [Header("Spin")]
    [SerializeField] private float _spinSpeed = 720f;

    [Header("Explosion")]
    [SerializeField] private GameObject _explosionPrefab;

    private HashSet<int> _hitMonsterIds = new();  // 이미 히트한 몬스터 추적
    ...
}
```

### 3가지 Init 오버로드

> **왜 하나의 클래스에 3가지 Init을 통합했는가?** 투사체 종류별(플레이어용, 몬스터용, Arc용)로 클래스를 분리하면 ObjectPool에서 타입별 풀을 따로 관리해야 하고, 공통 이동/피격 로직이 중복된다. 하나의 `ProjectileBase`에 Init 오버로드로 통합하면 **풀링이 단순해지고, 이동/충돌 로직을 한 곳에서 관리**할 수 있다.

```csharp
// 1. 기본 초기화 (몬스터 투사체)
public void Init(float damage) { ... }

// 2. 업그레이드 데이터 초기화 (플레이어 투사체)
public void Init(ProjectileInitData data) { ... }

// 3. Arc 초기화 (Nepenthes 포탑)
public void Init(float damage, Vector3 targetPos) { ... }
```

## 이동 타입별 로직

### Straight / Piercing

> **왜 Raycast가 아닌 SphereCast인가?** 일반 Raycast는 선(두께 0)으로 충돌을 검사하므로, 투사체가 벽 모서리를 스치면 감지하지 못하고 벽을 뚫는 문제가 생긴다. SphereCast는 **투사체의 실제 크기(`_bounceRadius`)를 반영**하여 구체로 검사하므로, 모서리 근처에서도 정확한 벽 반사가 일어난다.

```csharp
private void UpdateStraight()
{
    if (_bounceEnabled)
    {
        // 벽 반사 모드: SphereCast로 BlockObstacle 감지
        float dt = Time.deltaTime;
        float stepDist = _velocity.magnitude * dt;

        if (stepDist > 0f && Physics.SphereCast(  // ①
            transform.position, _bounceRadius, _velocity.normalized,
            out RaycastHit hit, stepDist))
        {
            if (hit.collider.GetComponent<BlockObstacle>() != null)
            {
                // 벽 법선 기준 반사
                Vector3 normal = hit.normal;
                normal.y = 0; normal.Normalize();
                _velocity = Vector3.Reflect(_velocity, normal);  // ②
                _bounceCount++;

                if (_bounceCount >= _maxBounces)
                {
                    Explode();  // 최대 반사 초과 시 폭발
                    return;
                }
            }
        }
        transform.position += _velocity * dt;
    }
    else
    {
        // 일반 직선 이동
        transform.position += _moveDirection * _speed * Time.deltaTime;
    }

    // 플레이어 투사체 회전 연출
    if (_isPlayerProjectile && _spinSpeed > 0f)
        transform.Rotate(Vector3.up, _spinSpeed * Time.deltaTime, Space.Self);  // ③
}
```

#### 코드 해설
| # | 설명 |
|---|------|
| ① | `SphereCast`는 반지름 `_bounceRadius`의 구체를 이동 방향으로 쏘아 벽 충돌을 감지한다. 일반 Raycast(선)와 달리 투사체의 실제 크기를 반영하므로 모서리 근처에서도 정확히 반사된다 |
| ② | 입사 벡터(`_velocity`)를 벽의 법선(`normal`) 기준으로 반사한다. 입사각 = 반사각 물리 법칙을 한 줄로 구현한다 |
| ③ | 플레이어 투사체에 Y축 회전을 적용하여 날아가면서 빙글빙글 도는 시각 효과를 연출한다 |

### Arc (포물선)

> **왜 `4h·t·(1-t)` 공식인가?** 이 식은 `t=0`에서 0, `t=0.5`에서 최대값 `h`, `t=1`에서 다시 0이 되는 **대칭 포물선**을 만든다. 물리 시뮬레이션(중력 + 초기속도)으로도 포물선을 만들 수 있지만, 시간 `t`에 대해 정확히 제어할 수 없어 착지 지점이 달라질 수 있다. 이 공식은 **시작점과 끝점이 보장**되면서도 자연스러운 곡선을 생성하여, 포탑형 몬스터가 정확히 플레이어 위치에 투사체를 떨어뜨릴 수 있다.

```csharp
private void UpdateArc()
{
    _elapsed += Time.deltaTime;
    float t = _elapsed / _arcDuration;  // ①

    if (t >= 1f)
    {
        transform.position = _targetPos;
        ReturnToPool();
        return;
    }

    // 선형 보간 + 사인 곡선으로 포물선 생성
    Vector3 pos = Vector3.Lerp(_startPos, _targetPos, t);  // ②
    pos.y += _arcHeight * 4f * t * (1f - t);  // ③ y = 4h·t·(1-t) 포물선
    transform.position = pos;
}
```

#### 코드 해설
| # | 설명 |
|---|------|
| ① | 경과 시간을 전체 비행 시간으로 나누어 0~1 범위의 정규화된 진행률을 구한다. t=0이 출발, t=1이 도착 |
| ② | 시작점과 목표점을 t 비율로 선형 보간하여 XZ 평면상의 수평 위치를 결정한다 |
| ③ | `4h·t·(1-t)`는 t=0.5에서 최대값 h를 가지는 대칭 포물선이다. 시작과 끝에서 0이 되므로 출발점과 착지점이 정확히 보장된다 |

### 이동 타입 비교

```
Straight:   ────────────────────→  (직선, 수명 종료 시 반환)
            벽 반사: ────╲
                        ╲────→  (SphereCast 반사)

Arc:        ╱‾‾‾╲                  (포물선, _arcDuration 후 착지)
           ╱     ╲
          ╱       ╲

Piercing:   ────◆──◆──◆────→    (관통, 다중 히트, _hitMonsterIds로 중복 방지)
```

## 피격 판정 코드 흐름

> **왜 `HashSet<int> _hitMonsterIds`가 필요한가?** 관통 투사체는 몬스터를 통과하며 계속 이동한다. `OnTriggerEnter`는 물리 엔진 특성상 같은 몬스터에 대해 여러 프레임에 걸쳐 호출될 수 있다. HashSet으로 이미 히트한 몬스터의 InstanceID를 기록하면, **같은 몬스터에 다중 히트되는 버그를 O(1) 비용으로 방지**한다.

> **왜 리코셰 > 관통 > 파괴 순서인가?** 리코셰(적 간 도탄)는 새 타겟으로 방향이 바뀌어 가장 역동적인 시각 효과를 준다. 관통은 방향을 유지하며 뒤쪽 적도 맞출 수 있다. 리코셰를 먼저 체크하면 **리코셰 횟수가 남아있는 한 가장 재미있는 결과가 우선 적용**되고, 리코셰가 소진되면 관통으로 폴백, 둘 다 없으면 파괴된다. 게임의 쾌감을 극대화하는 의도적 우선순위다.

```csharp
private void OnTriggerEnter(Collider other)
{
    // 1. Block 충돌 처리
    if (other.GetComponent<BlockObstacle>() != null)
    {
        if (_moveType == EProjectileMoveType.Arc) return;  // Arc는 무시
        if (_bounceEnabled) return;  // SphereCast에서 처리
        _hasHit = true;
        ReturnToPool();
        return;
    }

    // 2. 플레이어 투사체 → 몬스터 피격
    if (_isPlayerProjectile)
    {
        MonsterBase monster = other.GetComponent<MonsterBase>();
        if (monster != null)
        {
            int mId = monster.GetInstanceID();  // ①
            if (_hitMonsterIds.Contains(mId)) return;
            _hitMonsterIds.Add(mId);

            // ─── 헤드샷 판정 (보스 제외) ───
            if (_headshotChance > 0f && !monster.IsBoss
                && Random.value < _headshotChance)
            {
                monster.InstantKill();
                DamageTextSpawner.SpawnHeadshot(monster.transform.position + Vector3.up);
            }
            else
            {
                // ─── 크리티컬 판정 ───
                float finalDamage = _damage;
                bool isCrit = _critChance > 0f && Random.value < _critChance;
                if (isCrit)
                    finalDamage *= Random.Range(_critDamageMin, _critDamageMax);  // ②

                // ─── 넉백 ───
                if (_knockbackForce > 0f)
                    monster.Knockback(transform.forward, _knockbackForce);

                monster.TakeDamage(finalDamage, isCrit);
            }

            // ─── 리코셰 > 관통 > 파괴 우선순위 ───
            if (_ricochetCount > 0)  // ③
            {
                _ricochetCount--;
                MonsterBase next = FindNearestMonster(_ricochetRadius);
                if (next != null)
                {
                    // 다음 타겟으로 방향 전환
                    Vector3 dir = (next.transform.position - transform.position).normalized;
                    transform.forward = dir;
                    _moveDirection = dir;
                    return;  // 파괴하지 않고 계속
                }
            }

            if (_isPiercing) return;  // ④ 관통: 파괴하지 않고 계속

            _hasHit = true;
            ReturnToPool();
        }
    }
    // 3. 몬스터 투사체 → 플레이어 피격
    else
    {
        PlayerController player = other.GetComponent<PlayerController>();
        if (player != null)
        {
            _hasHit = true;
            player.TakeDamage(_damage);
            if (_bounceEnabled) Explode();
            else ReturnToPool();
        }
    }
}
```

#### 코드 해설
| # | 설명 |
|---|------|
| ① | 몬스터의 InstanceID를 HashSet에 기록하여, 관통 투사체가 같은 몬스터를 여러 프레임에 걸쳐 중복 히트하는 것을 O(1)로 방지한다 |
| ② | 크리티컬 발동 시 최소~최대 배율 사이에서 랜덤 값을 뽑아 데미지에 곱한다. 크리티컬마다 배율이 달라져 전투에 변동성을 준다 |
| ③ | 리코셰 잔여 횟수가 있으면, 가장 가까운 미피격 몬스터를 찾아 방향을 전환한다. 리코셰 → 관통 → 파괴 순으로 우선순위를 적용한다 |
| ④ | 관통 플래그가 켜져 있으면 몬스터를 히트해도 투사체를 파괴하지 않고 직진을 계속한다. HashSet이 중복 히트를 방지한다 |

### 피격 우선순위 플로우

```
OnTriggerEnter (몬스터 히트)
    │
    ├── 헤드샷 확률 체크 (보스 제외)
    │   ├── 성공 → InstantKill() + "헤드샷" 텍스트
    │   └── 실패 ↓
    │
    ├── 크리티컬 확률 체크
    │   ├── 성공 → damage × Random(critMin, critMax)
    │   └── 실패 → 기본 damage
    │
    ├── 넉백 적용 (force > 0)
    │
    ├── TakeDamage(finalDamage, isCrit)
    │
    └── 생존 판정:
        ├── 리코셰 남음? → 가장 가까운 미피격 몬스터로 방향 전환
        ├── 관통? → 계속 이동 (HashSet으로 중복 방지)
        └── → 풀 반환
```

## FireExplosion - 즉시 폭발 + DoT

> `Assets/Scripts/Projectile/FireExplosion.cs`

```csharp
public class FireExplosion : MonoBehaviour
{
    [SerializeField] private float _explosionRadius = 2f;
    [SerializeField] private float _lingerDuration = 2f;
    [SerializeField] private float _lingerDamageInterval = 0.5f;
    [SerializeField] private float _lingerDamageRatio = 0.3f;  // DoT = 원본의 30%

    private float _damage;

    public void Init(float damage) { _damage = damage; }

    private void OnEnable()
    {
        // 동적 SphereCollider 생성
        if (_sphereCollider == null)
        {
            _sphereCollider = gameObject.AddComponent<SphereCollider>();
            _sphereCollider.isTrigger = true;
            _sphereCollider.radius = _explosionRadius;
        }
        StartCoroutine(ExplosionRoutine());
    }

    private IEnumerator ExplosionRoutine()
    {
        // 즉시 폭발: OverlapSphere로 범위 내 플레이어 감지
        Collider[] hits = Physics.OverlapSphere(transform.position, _explosionRadius);
        foreach (Collider hit in hits)
        {
            PlayerController player = hit.GetComponent<PlayerController>();
            if (player != null)
            {
                player.TakeDamage(_damage);
                break;
            }
        }

        CameraController.Instance?.Shake(0.2f, 0.25f);

        // _lingerDuration 동안 잔류 → DoT
        yield return new WaitForSeconds(_lingerDuration);

        _sphereCollider.enabled = false;
        ObjectPool.Instance.Return(gameObject);
    }

    // 잔류 화염 DoT
    private void OnTriggerStay(Collider other)
    {
        PlayerController player = other.GetComponent<PlayerController>();
        if (player == null) return;

        _lingerDamageTimer -= Time.deltaTime;
        if (_lingerDamageTimer > 0f) return;

        player.TakeDamage(_damage * _lingerDamageRatio);  // 원본의 30%
        _lingerDamageTimer = _lingerDamageInterval;
    }
}
```

### 폭발 타임라인

```
Init(damage) → OnEnable()
    │
    ▼ 즉시
OverlapSphere → 범위 내 플레이어 데미지 (100%)
    + CameraShake
    │
    ▼ _lingerDuration (2초)
OnTriggerStay → 0.5초마다 DoT (30%)
    │
    ▼ 종료
ObjectPool.Return()
```
