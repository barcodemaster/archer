# 11. 50스테이지 밸런스 종합 설계

## 개요

50스테이지까지의 밸런스를 설계한다. 플레이어가 Lv1 Common 장비(무기+반지+상의+하의)를 기준으로,
난이도 스케일링(선형 6%)과 함께 공정하면서도 도전적인 게임 경험을 제공하는 것이 목표.

---

## 설계 기반 수치

- **플레이어**: HP 1000, Attack 50 → Lv1 장비 착용 시 HP ~1020, Attack ~70
- **난이도 배율**: `1.0 + stageIndex * 0.06` (Stage 10=1.6x, 30=2.8x, 50=4.0x)
- **스테이지 구조**: Start(0) + [Normal×4 + Angel + Normal×4 + Boss] × 5존
- **맵 크기**: 일반 11×15, 보스 11×20

---
