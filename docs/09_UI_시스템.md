## UIManager - 레이어 관리

> `Assets/Scripts/Manager/UIManager.cs`

> **왜 ForceReset이 필요한가?** 플레이어가 조이스틱을 드래그하는 도중에 레벨업이 발동되면, 조이스틱의 OnPointerUp이 호출되지 않아 `JoystickDir`이 마지막 방향으로 고정된다. 이 상태에서 레벨업 UI가 닫히면 **캐릭터가 입력 없이 한 방향으로 계속 이동하는** 버그가 생긴다. UI 전환 시 `ForceReset()`으로 조이스틱 상태를 초기화하여 이 문제를 방지한다.

> **왜 EventSystem을 1프레임 disable하는가?** Unity의 EventSystem은 포인터 상태(드래그 중, 호버 등)를 내부적으로 캐싱한다. UI 레이어를 전환해도 이전 포인터 상태가 남아있어, 새 UI에서 의도치 않은 클릭이나 드래그가 발생할 수 있다. 1프레임 동안 disable하면 **EventSystem이 모든 포인터 상태를 초기화**하여 깨끗한 상태에서 새 UI 입력을 받을 수 있다.

```csharp
public class UIManager : Singleton<UIManager>
{
    [SerializeField] private GameObject _joystickLayer;
    [SerializeField] private GameObject _levelUpLayer;
    [SerializeField] private GameObject _pauseLayer;
    [SerializeField] private GameObject _stageProgressLayer;
    [SerializeField] private GameObject _equipmentLayer;

    private Image _fadeImage;  // 동적 생성 fullscreen 검정 이미지

    private void Start()
    {
        CreateFadeImage();  // Canvas에 FadeOverlay 동적 생성
    }

    // 페이드 아웃: alpha 0→1 (화면 어두워짐)
    public Coroutine FadeOut(float duration = 0.5f)
    {
        return StartCoroutine(FadeCoroutine(0f, 1f, duration));
    }

    // 페이드 인: alpha 1→0 (화면 밝아짐)
    public Coroutine FadeIn(float duration = 0.5f)
    {
        return StartCoroutine(FadeCoroutine(1f, 0f, duration));
    }

    // 레벨업 표시: 조이스틱 숨김 + 조이스틱 ForceReset
    public void ShowLevelUp()
    {
        if (_joystickLayer != null)
        {
            UI_Joystick joystick = _joystickLayer.GetComponentInChildren<UI_Joystick>();
            if (joystick != null) joystick.ForceReset();
            _joystickLayer.SetActive(false);
        }
        if (_levelUpLayer != null) _levelUpLayer.SetActive(true);
    }

    // 장비창: 시간 정지 + 조이스틱 리셋
    public void ShowEquipment()
    {
        // 조이스틱 ForceReset + 숨기기
        ...
        if (_equipmentLayer != null)
        {
            _equipmentLayer.SetActive(true);
            var panel = _equipmentLayer.GetComponent<UI_EquipmentPanel>();
            if (panel != null) panel.Open();
        }
        Time.timeScale = 0f;
        GameManager.Instance.IsPaused = true;
    }

    // EventSystem 리셋 (1프레임 disable → 포인터 상태 초기화)
    public void ResetEventSystem()
    {
        var eventSystem = EventSystem.current;
        if (eventSystem != null)
        {
            eventSystem.SetSelectedGameObject(null);
            eventSystem.enabled = false;
            StartCoroutine(ReenableEventSystem(eventSystem));
        }
    }
}
```

## UI_Joystick - 가상 조이스틱

> `Assets/Scripts/UI/UI_Joystick.cs`

```csharp
public class UI_Joystick : MonoBehaviour,
    IPointerDownHandler, IPointerUpHandler, IDragHandler
{
    [SerializeField] private GameObject _background;
    [SerializeField] private GameObject _cursor;

    private Vector2 _cursorStartPos;
    private Vector2 _backgroundStartPos;
    private float _radius;
    private Vector2 _touchPos;

    public void Start()
    {
        _cursorStartPos = _cursor.transform.position;
        _backgroundStartPos = _background.transform.position;
        _radius = _background.GetComponent<RectTransform>().sizeDelta.y / 3;
    }

    public void OnPointerDown(PointerEventData eventData)
    {
        // 터치 위치로 조이스틱 이동 (팔로우 방식)
        _background.transform.position = eventData.position;
        _cursor.transform.position = eventData.position;
        _touchPos = eventData.position;
    }

    public void OnPointerUp(PointerEventData eventData)
    {
        // 원래 위치로 복귀
        _cursor.transform.position = _cursorStartPos;
        _background.transform.position = _backgroundStartPos;
        GameManager.Instance.JoystickDir = Vector2.zero;
    }

    public void OnDrag(PointerEventData eventData)
    {
        Vector2 touchDir = (eventData.position - _touchPos);
        float moveDist = Mathf.Min(touchDir.magnitude, _radius);
        Vector2 moveDir = touchDir.normalized;
        Vector2 newPosition = _touchPos + moveDir * moveDist;
        _cursor.transform.position = newPosition;

        GameManager.Instance.JoystickDir = moveDir;  // 글로벌 입력 전달
    }

    // 외부 강제 리셋 (레벨업 등 UI 전환 시)
    public void ForceReset()
    {
        _cursor.transform.position = _cursorStartPos;
        _background.transform.position = _backgroundStartPos;
        GameManager.Instance.JoystickDir = Vector2.zero;
    }
}
```

### 조이스틱 입력 흐름

```
터치 다운
    │  _touchPos = 터치 위치
    ▼
배경/커서를 터치 위치로 이동 (팔로우)
    │
    ▼ 드래그
touchDir = 현재 위치 - _touchPos
moveDist = min(touchDir.magnitude, _radius)
    │
    ▼
커서 이동 (반경 클램프)
GameManager.JoystickDir = moveDir
    │
    ▼ 터치 업
원래 위치 복귀
JoystickDir = zero
```

## UI_LevelUp - 룰렛 레벨업

> `Assets/Scripts/UI/UI_LevelUp.cs`

> **왜 `WaitForSecondsRealtime`인가?** 레벨업 UI가 열리면 `Time.timeScale = 0`으로 게임이 정지된다. 일반 `WaitForSeconds`는 TimeScale의 영향을 받으므로, `timeScale=0`이면 영원히 기다린다. `WaitForSecondsRealtime`은 **실제 경과 시간 기준으로 동작**하여, 게임이 정지된 상태에서도 룰렛 애니메이션이 정상적으로 진행된다.

```csharp
public class UI_LevelUp : MonoBehaviour
{
    [SerializeField] private UI_UpgradeSlot[] _slots;  // 3개 슬롯
    [SerializeField] private float _spinDuration = 2.0f;
    [SerializeField] private float _stopInterval = 0.5f;
    [SerializeField] private float _delayShowPanel = 1.5f;

    private Queue<int> _pendingLevelUps = new Queue<int>();
    private int _tapCount;
    private bool _isAnimating;

    private void Start()
    {
        // ExpManager 레벨업 이벤트 구독
        ExpManager.Instance.OnLevelUp += OnLevelUp;

        // 각 슬롯 버튼에 선택 콜백 등록
        for (int i = 0; i < _slots.Length; i++)
        {
            int idx = i;
            _slots[i].GetComponentInChildren<Button>()
                .onClick.AddListener(() => OnSlotSelected(idx));
        }
    }

    private void OnLevelUp(int level)
    {
        _pendingLevelUps.Enqueue(level);  // ① 큐로 연속 레벨업 대응
        if (!_isShowing)
            StartCoroutine(ShowDelay());  // 1.5초 딜레이 후 표시
    }

    private void Show(int level)
    {
        _isShowing = true;
        UIManager.Instance.ShowLevelUp();
        Time.timeScale = 0f;
        GameManager.Instance.IsPaused = true;

        // EventSystem 리셋 (드래그 상태 해제)
        UIManager.Instance.ResetEventSystem();

        // 3개 슬롯에 랜덤 업그레이드 배치 + 스핀 시작
        List<UpgradeInfo> picks = UpgradeDatabase.PickRandom(3);
        for (int i = 0; i < _slots.Length; i++)
        {
            _slots[i].SetUpgrade(picks[i]);
            _slots[i].StartSpin();
        }

        _tapCount = 0;
        _isAnimating = true;
        _rouletteCoroutine = StartCoroutine(RouletteStopCoroutine());
    }

    // 패널 탭: 2회 이상 탭 시 스킵
    public void OnPanelTapped()
    {
        if (!_isAnimating) return;
        _tapCount++;
        if (_tapCount >= 2) SkipAnimation();
    }

    // 룰렛 자연 종료: 2초 스핀 → 0.5초 간격으로 순차 정지
    private IEnumerator RouletteStopCoroutine()
    {
        yield return new WaitForSecondsRealtime(_spinDuration);  // ②

        for (int i = 0; i < _slots.Length; i++)
        {
            _slots[i].StopSpin();
            if (i < _slots.Length - 1)
                yield return new WaitForSecondsRealtime(_stopInterval);
        }

        for (int i = 0; i < _slots.Length; i++)
            _slots[i].SetInteractable(true);

        _isAnimating = false;
    }

    // 슬롯 선택 → 업그레이드 적용
    private void OnSlotSelected(int idx)
    {
        UpgradeInfo selected = _slots[idx].Assigned;
        PlayerController player = FindAnyObjectByType<PlayerController>();
        if (player != null)
        {
            PlayerUpgrade upgrade = player.GetComponent<PlayerUpgrade>();
            if (upgrade != null) upgrade.AddUpgrade(selected.type);
            player.ApplyUpgradeEffect(selected.type);
        }

        if (_pendingLevelUps.Count > 0)
            Show(_pendingLevelUps.Dequeue());  // ③ 다음 레벨업
        else
            Close();
    }
}
```

#### 코드 해설
| # | 설명 |
|---|------|
| ① | 경험치가 한 번에 많이 들어와 연속 레벨업이 발생하면, Queue에 순서대로 쌓아둔다. 한 번에 하나씩 처리하여 레벨업이 씹히지 않는다 |
| ② | `WaitForSecondsRealtime`은 `Time.timeScale`에 영향받지 않는다. 게임이 정지(timeScale=0)된 상태에서도 2초 후 룰렛이 멈추는 연출이 정상 동작한다 |
| ③ | 현재 레벨업 선택이 끝나면 큐에서 다음 대기 중인 레벨업을 꺼내 연속으로 보여준다. 큐가 비면 UI를 닫고 게임을 재개한다 |

### 레벨업 타임라인

```
ExpManager.OnLevelUp(level)
    │
    ▼ 1.5초 딜레이
Show(level)
    ├── TimeScale = 0 (게임 정지)
    ├── 3개 슬롯 스핀 시작
    │
    ├── [자연 종료 경로]
    │   ├── 2초 스핀 (WaitForSecondsRealtime)
    │   ├── 슬롯1 정지 → 0.5초 → 슬롯2 정지 → 0.5초 → 슬롯3 정지
    │   └── 3개 슬롯 인터랙션 활성화
    │
    └── [스킵 경로]
        └── 2회 탭 → 즉시 전체 정지 + 인터랙션 활성화

슬롯 선택
    ├── PlayerUpgrade.AddUpgrade()
    ├── PlayerController.ApplyUpgradeEffect()
    │
    ├── 대기 중 레벨업 있음? → Show(다음 레벨)
    └── 없음 → Close() → TimeScale = 1
```

## UI_EquipmentPanel - 장비 패널

> `Assets/Scripts/UI/UI_EquipmentPanel.cs`

> **왜 별도 카메라 + RenderTexture로 프리뷰하는가?** 메인 카메라로 캐릭터 모델을 찍으면 게임 월드의 몬스터, 타일 등이 함께 렌더링된다. 별도 카메라를 "EquipmentModel" 레이어만 렌더링하도록 설정하고, RenderTexture에 출력하면 **게임 월드와 완전히 독립된 깨끗한 장비 프리뷰**를 UI에 표시할 수 있다. `AnimatorUpdateMode.UnscaledTime`으로 TimeScale=0에서도 Idle 애니메이션이 재생된다.

```csharp
public class UI_EquipmentPanel : MonoBehaviour
{
    [Header("Equip Slots")]
    [SerializeField] private UI_EquipSlot[] _equipSlots;

    [Header("Inventory")]
    [SerializeField] private Transform _inventoryContent;
    [SerializeField] private GameObject _itemSlotPrefab;

    [Header("Player Model")]
    [SerializeField] private RawImage _playerModelImage;
    [SerializeField] private Camera _modelCamera;
    [SerializeField] private Transform _modelSpawnPoint;
    [SerializeField] private GameObject _playerModelPrefab;

    private RenderTexture _renderTexture;
    private GameObject _modelInstance;

    public void Open()
    {
        SetupPlayerModel();   // RenderTexture 3D 프리뷰
        Refresh();
        EquipmentManager.Instance.OnEquipChanged += Refresh;
    }

    // RenderTexture 기반 플레이어 모델 프리뷰
    private void SetupPlayerModel()
    {
        // 512x512 RenderTexture 생성
        _renderTexture = new RenderTexture(512, 512, 16, RenderTextureFormat.ARGB32);
        _modelCamera.targetTexture = _renderTexture;
        _playerModelImage.texture = _renderTexture;

        // 투명 배경 설정
        _modelCamera.clearFlags = CameraClearFlags.SolidColor;
        _modelCamera.backgroundColor = Color.clear;

        // 플레이어 모델 클론 생성
        _modelInstance = Instantiate(source, _modelSpawnPoint.position,
            _modelSpawnPoint.rotation);

        // 불필요한 컴포넌트 비활성화
        pc.enabled = false;  // PlayerController
        cc.enabled = false;  // CharacterController

        // EquipmentModel 레이어 설정 (별도 카메라 렌더링)
        int modelLayer = LayerMask.NameToLayer("EquipmentModel");
        SetLayerRecursive(_modelInstance, modelLayer);

        // Idle 애니메이션 (UnscaledTime으로 TimeScale=0에서도 동작)
        Animator anim = _modelInstance.GetComponentInChildren<Animator>();
        anim.updateMode = AnimatorUpdateMode.UnscaledTime;
        anim.Play(Define.IDLE);

        // Renderer bounds 기반 카메라 자동 프레이밍
        FrameCameraOnModel();
    }

    // Renderer bounds 기반 카메라 거리 자동 계산
    private void FrameCameraOnModel()
    {
        Renderer[] renderers = _modelInstance.GetComponentsInChildren<Renderer>();
        Bounds bounds = renderers[0].bounds;
        for (int i = 1; i < renderers.Length; i++)
            bounds.Encapsulate(renderers[i].bounds);

        // FOV와 bounds로 필요 거리 계산 (패딩 1.5배)
        float distanceForHeight = (boundsHeight * 1.5f * 0.5f)
            / Mathf.Tan(fov * 0.5f * Mathf.Deg2Rad);  // ①
        float distanceForWidth = (boundsWidth * 1.5f * 0.5f)
            / Mathf.Tan(horizontalFov * 0.5f * Mathf.Deg2Rad);
        float distance = Mathf.Max(distanceForHeight, distanceForWidth);  // ②

        _modelCamera.transform.position = bounds.center
            + _modelInstance.transform.forward * distance;
        _modelCamera.transform.LookAt(bounds.center);
    }

    // 인벤토리 목록 갱신 (GridLayoutGroup, 5열)
    private void RefreshInventoryList()
    {
        // 기존 슬롯 정리
        foreach (var go in _spawnedSlots) if (go != null) Destroy(go);
        _spawnedSlots.Clear();

        // 미장착 아이템만 표시
        foreach (var item in EquipmentManager.Instance.Inventory)
        {
            if (item.isEquipped) continue;
            GameObject go = Instantiate(_itemSlotPrefab, _inventoryContent);
            UI_ItemSlot slot = go.GetComponent<UI_ItemSlot>();
            slot.SetItem(item, table, this);
            _spawnedSlots.Add(go);
        }
    }
}
```

#### 코드 해설
| # | 설명 |
|---|------|
| ① | FOV의 절반 탄젠트로 모델의 높이(×1.5 패딩)를 나누어, 모델이 화면에 꽉 차는 카메라 거리를 삼각함수로 역산한다 |
| ② | 높이 기준 거리와 너비 기준 거리 중 더 큰 값을 택하여, 모델이 가로/세로 어느 방향으로도 잘리지 않게 한다 |

## DamageText / LevelUpText - 플로팅 텍스트

### DamageText

> `Assets/Scripts/UI/DamageText.cs`

```csharp
public class DamageText : MonoBehaviour
{
    [SerializeField] private float _riseSpeed = 1.5f;
    [SerializeField] private float _duration = 1f;

    private TextMeshPro _tmp;
    private float _elapsed;
    private Color _color;

    public void Init(float damage, bool isPlayer)
    {
        _tmp = GetComponent<TextMeshPro>();
        _tmp.text = Mathf.RoundToInt(damage).ToString();
        _color = Color.white;
    }

    public void Init(string text, Color color)
    {
        _tmp.text = text;
        _color = color;  // 헤드샷: 빨강, 크리티컬: 빨강
    }

    private void Update()
    {
        _elapsed += Time.deltaTime;
        transform.position += Vector3.up * _riseSpeed * Time.deltaTime;

        float alpha = Mathf.Clamp01(1f - _elapsed / _duration);
        _tmp.color = new Color(_color.r, _color.g, _color.b, alpha);

        // 빌보드: 카메라 방향 유지
        if (Camera.main != null)
            transform.rotation = Camera.main.transform.rotation;

        if (_elapsed >= _duration)
            ObjectPool.Instance.Return(gameObject);
    }
}
```

## HPBar 시스템

### HPBar (베이스)

> **왜 LateUpdate에서 카메라 rotation을 복사하는가?** HP바는 3D 월드에 배치된 오브젝트지만, 탑뷰 카메라에서 항상 읽을 수 있어야 한다. `Update`에서 회전을 설정하면 카메라가 같은 프레임에 이동한 뒤 HP바가 한 프레임 뒤처진다. `LateUpdate`에서 카메라의 현재 rotation을 복사하면 **카메라 이동 후에 빌보드가 적용**되어 항상 정확히 카메라를 향한다.

```csharp
public class HPBar : MonoBehaviour
{
    [SerializeField] protected Slider _slider;

    public virtual void SetHP(float current, float max)
    {
        if (_slider != null && max > 0)
            _slider.value = current / max;
    }

    protected virtual void LateUpdate()
    {
        // 빌보드: 탑뷰 카메라를 향하도록 회전
        if (Camera.main != null)
            transform.rotation = Camera.main.transform.rotation;
    }
}
```

### PlayerHPBar (텍스트 + 200HP 구분선)

> **왜 200HP 구분선이 필요한가?** HP가 2000까지 올라가면 HP바만 보고는 현재 HP가 1200인지 1400인지 감각적으로 파악하기 어렵다. 200HP마다 구분선을 표시하면 **시각적 눈금자 역할**을 하여, 플레이어가 "아직 HP가 3칸(600) 남았다"처럼 직관적으로 잔여 체력을 인식할 수 있다.

```csharp
public class PlayerHPBar : HPBar
{
    [SerializeField] private Text _hpText;
    [SerializeField] private RectTransform _dividerContainer;
    [SerializeField] private GameObject _dividerPrefab;

    public override void SetHP(float current, float max)
    {
        base.SetHP(current, max);
        if (_hpText != null) _hpText.text = $"{(int)current}";

        // 최대 HP 변경 시 구분선 재생성
        if (max != _lastMaxHp)
        {
            _lastMaxHp = max;
            RebuildDividers(max);
        }
    }

    // 200HP 단위 구분선 (앵커 기반 정확한 위치)
    private void RebuildDividers(float maxHp)
    {
        int dividerCount = (int)(maxHp / 200f);  // ①
        for (int i = 1; i < dividerCount + 1; i++)
        {
            float ratio = (i * 200f) / maxHp;  // ②
            if (ratio >= 1f) break;
            // ratio 위치에 2px 너비 구분선 배치
        }
    }
}
```

#### 코드 해설
| # | 설명 |
|---|------|
| ① | 최대 HP를 200으로 나누어 필요한 구분선 개수를 계산한다. 예: maxHp=1000이면 5개의 구분선(200, 400, 600, 800, 1000 위치) |
| ② | `i × 200 / maxHp`로 구분선의 HP바 내 비율 위치(0~1)를 계산한다. 이 비율을 앵커로 변환하여 구분선을 정확한 위치에 배치한다 |

## UI_StageProgress - 스테이지 진행도

> `Assets/Scripts/UI/UI_StageProgress.cs`

> **왜 ease-out 보간을 사용하는가?** 선형 보간(`t`)으로 슬라이더를 채우면 시작부터 끝까지 동일한 속도로 움직여 밋밋하다. ease-out(`1 - (1-t)²`)은 **처음에 빠르게 채워지다가 끝에서 감속**하여, "목표에 도달한다"는 느낌을 강화하는 자연스러운 애니메이션이 된다.

```csharp
public class UI_StageProgress : MonoBehaviour
{
    [SerializeField] private Slider _progressSlider;
    [SerializeField] private Slider _progressSlider2;
    [SerializeField] private TextMeshProUGUI _currentStageText;
    [SerializeField] private TextMeshProUGUI _nextStageText;
    [SerializeField] private TextMeshProUGUI _nextNextStageText;
    [SerializeField] private TextMeshProUGUI _totalText;
    [SerializeField] private float _sliderFillDuration = 1.0f;
    [SerializeField] private float _punchScaleSize = 1.4f;

    private void Start()
    {
        StageManager.Instance.OnExitDoorOpened += OnExitDoorOpened;  // ①
        gameObject.SetActive(false);
    }

    private void PopulateStageNumbers(int current, int total)
    {
        _isNearEnd = (current + 2) > total;

        // 3개의 이정표 번호 계산
        int pos1 = _isNearEnd ? current - 1 : current;
        int pos2 = _isNearEnd ? current : current + 1;
        int pos3 = _isNearEnd ? current + 1 : current + 2;

        _currentStageText.text = pos1.ToString();
        _nextStageText.text = pos2.ToString();
        _nextNextStageText.text = pos3.ToString();

        // 5단위 마일스톤 표시
        int milestone = ((pos3 / 5) + 1) * 5;                 // ②
        bool showMilestone = milestone > pos3 && milestone <= total;
        if (showMilestone)
            _totalText.text = $"{milestone}/{total}";
        _totalText.gameObject.SetActive(showMilestone);
    }

    private IEnumerator StageProgressSequence()
    {
        yield return new WaitForSeconds(_panelShowDelay);
        AudioManager.Instance?.PlayStageProgress();

        Slider targetSlider = _isNearEnd ? _progressSlider2 : _progressSlider;

        // ease-out 슬라이더 채우기
        float elapsed = 0f;
        while (elapsed < _sliderFillDuration)
        {
            elapsed += Time.deltaTime;
            float t = Mathf.Clamp01(elapsed / _sliderFillDuration);
            float eased = 1f - (1f - t) * (1f - t);           // ③ ease-out
            targetSlider.value = eased;
            yield return null;
        }
        targetSlider.value = 1f;

        // 펀치스케일: 도착 텍스트에 팝 효과
        Transform punchTarget = _isNearEnd
            ? _nextNextStageText.transform
            : _nextStageText.transform;
        Vector3 original = punchTarget.localScale;
        Vector3 punch = original * _punchScaleSize;            // ④

        // scale up (30%) → scale down (70%)
        float upDuration = _punchScaleDuration * 0.3f;
        elapsed = 0f;
        while (elapsed < upDuration)
        {
            elapsed += Time.deltaTime;
            punchTarget.localScale = Vector3.Lerp(original, punch,
                Mathf.Clamp01(elapsed / upDuration));
            yield return null;
        }
        float downDuration = _punchScaleDuration * 0.7f;
        elapsed = 0f;
        while (elapsed < downDuration)
        {
            elapsed += Time.deltaTime;
            punchTarget.localScale = Vector3.Lerp(punch, original,
                Mathf.Clamp01(elapsed / downDuration));
            yield return null;
        }
        punchTarget.localScale = original;

        yield return new WaitForSeconds(_autoCloseDelay);
        UIManager.Instance.HideStageProgress();
    }
}
```

#### 코드 해설
| # | 설명 |
|---|------|
| ① | `OnExitDoorOpened` 이벤트를 구독하여 스테이지 클리어 시 자동으로 진행도 패널을 표시한다 |
| ② | `((pos3/5)+1)*5`로 다음 5단위 마일스톤을 계산한다. 예: pos3=7이면 milestone=10, pos3=14이면 milestone=15 |
| ③ | `1 - (1-t)²` ease-out 공식: t=0에서 기울기가 가파르고 t=1에 가까워질수록 완만해진다. 슬라이더가 처음에 빠르게 차다가 목표 근처에서 감속한다 |
| ④ | 텍스트를 1.4배 확대 후 원래 크기로 되돌리는 펀치 스케일. 30%의 시간 동안 빠르게 확대하고 70% 시간 동안 천천히 축소하여 "탄성" 있는 팝 효과를 만든다 |

## UI_PausePanel - 일시정지 패널

> `Assets/Scripts/UI/UI_PausePanel.cs`

> **왜 동적 툴팁을 코드로 생성하는가?** 프리팹으로 미리 만들면 수정 시 프리팹을 찾아 에디터에서 편집해야 한다. 코드로 생성하면 **폰트 크기, 색상, 레이아웃을 변수로 제어**할 수 있어, Inspector에서 실시간으로 조정하기 쉽다. 또한 프리팹 의존성이 없어 패널 프리팹만으로 완결된다.

```csharp
public class UI_PausePanel : MonoBehaviour
{
    [SerializeField] private GameObject _panel;
    [SerializeField] private Button _pauseButton;
    [SerializeField] private Button _resumeButton;
    [SerializeField] private Transform _skillIconContainer;
    [SerializeField] private SkillIconPool _skillIconPool;
    [SerializeField] private float _iconAnimInterval = 0.1f;

    public void OnPauseClicked()
    {
        Time.timeScale = 0f;
        GameManager.Instance.IsPaused = true;
        _panel.SetActive(true);
        UIManager.Instance.ShowPause();

        // 기존 아이콘 제거 → 풀에 반환
        for (int i = _skillIconContainer.childCount - 1; i >= 0; i--)
            _skillIconPool.Release(_skillIconContainer.GetChild(i).gameObject);  // ①

        // 습득한 스킬 아이콘 표시
        PlayerUpgrade playerUpgrade = FindAnyObjectByType<PlayerUpgrade>();
        if (playerUpgrade != null)
        {
            UpgradeInfo[] allUpgrades = UpgradeDatabase.GetAll();
            foreach (var info in allUpgrades)
            {
                if (playerUpgrade.GetLevel(info.type) > 0)
                {
                    GameObject iconObj = _skillIconPool.Get(_skillIconContainer);  // ②
                    var img = iconObj.GetComponent<Image>();
                    if (img != null && info.icon != null)
                        img.sprite = info.icon;

                    iconObj.transform.localScale = Vector3.zero;  // ③

                    Button btn = iconObj.GetComponent<Button>();
                    if (btn == null) btn = iconObj.AddComponent<Button>();
                    btn.onClick.RemoveAllListeners();
                    btn.onClick.AddListener(() => ShowTooltip(iconRect, info));
                }
            }
        }
        StartCoroutine(AnimateIcons());
    }

    private IEnumerator AnimateIcons()
    {
        for (int i = 0; i < _skillIconContainer.childCount; i++)
        {
            Transform icon = _skillIconContainer.GetChild(i);
            StartCoroutine(PunchScale(icon));                   // ④
            yield return new WaitForSecondsRealtime(_iconAnimInterval);
        }
    }

    // 스케일 0 → 1.2 → 1.0 팝 애니메이션
    private IEnumerator PunchScale(Transform target)
    {
        float elapsed = 0f;
        while (elapsed < 0.2f)
        {
            elapsed += Time.unscaledDeltaTime;                  // ⑤
            target.localScale = Vector3.one * Mathf.Lerp(0f, 1.2f,
                Mathf.Clamp01(elapsed / 0.2f));
            yield return null;
        }
        elapsed = 0f;
        while (elapsed < 0.1f)
        {
            elapsed += Time.unscaledDeltaTime;
            target.localScale = Vector3.one * Mathf.Lerp(1.2f, 1f,
                Mathf.Clamp01(elapsed / 0.1f));
            yield return null;
        }
        target.localScale = Vector3.one;
    }

    private IEnumerator HidePanel()
    {
        float elapsed = 0f;
        while (elapsed < _panelFadeDuration)
        {
            elapsed += Time.unscaledDeltaTime;
            _canvasGroup.alpha = Mathf.Lerp(1f, 0f,
                elapsed / _panelFadeDuration);                  // ⑥
            yield return null;
        }
        _panel.SetActive(false);
        Time.timeScale = 1f;
        GameManager.Instance.IsPaused = false;
    }
}
```

#### 코드 해설
| # | 설명 |
|---|------|
| ① | 이전에 표시된 아이콘을 역순으로 순회하며 풀에 반환한다. 역순 순회로 인덱스 변동 없이 안전하게 제거한다 |
| ② | `SkillIconPool.Get(container)`로 풀에서 아이콘을 가져와 컨테이너 하위에 배치한다 |
| ③ | 초기 스케일을 0으로 설정하여 AnimateIcons에서 순차적으로 팝 애니메이션을 적용할 준비를 한다 |
| ④ | 각 아이콘을 0.1초 간격으로 순차적 팝 애니메이션한다. 한꺼번에 나타나는 것보다 물결처럼 나타나는 것이 시각적으로 세련되다 |
| ⑤ | `Time.unscaledDeltaTime`을 사용하여 TimeScale=0 상태에서도 애니메이션이 진행된다 |
| ⑥ | CanvasGroup의 alpha를 1→0으로 보간하여 부드러운 페이드아웃 후 패널을 비활성화한다 |

## SkillIconPool - Stack 기반 UI 풀링

> `Assets/Scripts/Utils/SkillIconPool.cs`

> **왜 ObjectPool과 별도로 UI 전용 풀을 만들었는가?** `ObjectPool`은 3D 게임 오브젝트를 프리팹 이름 기반으로 관리하며, 60초 만료 정리 로직이 있다. UI 아이콘은 **단일 프리팹만 사용**하고, 일시정지 패널이 열릴 때마다 빈번하게 Get/Release되므로 만료 정리가 불필요하다. 단순한 `Stack<GameObject>` 기반 풀이 더 가볍고 적합하다.

```csharp
public class SkillIconPool : MonoBehaviour
{
    [SerializeField] private GameObject _iconPrefab;
    [SerializeField] private int _initialSize = 20;

    private readonly Stack<GameObject> _pool = new();          // ① LIFO

    private void Awake()
    {
        for (int i = 0; i < _initialSize; i++)
        {
            var obj = Instantiate(_iconPrefab, transform);
            obj.SetActive(false);
            _pool.Push(obj);                                    // ② 사전 생성
        }
    }

    public GameObject Get(Transform parent = null)
    {
        GameObject obj;
        if (_pool.Count > 0)
        {
            obj = _pool.Pop();                                  // ③ 재활용
            obj.SetActive(true);
        }
        else
            obj = Instantiate(_iconPrefab);                     // ④ 풀 소진 시 신규 생성

        if (parent != null)
            obj.transform.SetParent(parent, false);
        return obj;
    }

    public void Release(GameObject obj)
    {
        obj.SetActive(false);
        obj.transform.SetParent(transform);                     // ⑤
        _pool.Push(obj);
    }
}
```

#### 코드 해설
| # | 설명 |
|---|------|
| ① | `Stack`(LIFO)을 사용하여 가장 최근에 반환된 오브젝트를 먼저 꺼낸다. 캐시 친화적인 접근 패턴이다 |
| ② | Awake에서 20개를 사전 생성하여, 최초 일시정지 시 Instantiate 호출 없이 즉시 아이콘을 배치할 수 있다 |
| ③ | 풀에 오브젝트가 있으면 Pop으로 꺼내 재활용한다. SetActive(true)로 활성화만 하면 된다 |
| ④ | 풀이 비었으면 새로 생성한다. 22개 이상의 업그레이드를 보유한 경우에만 발생한다 |
| ⑤ | Release 시 비활성화하고 풀 오브젝트의 자식으로 되돌린다. Hierarchy에서 숨겨지며 다음 Get에서 재활용된다 |
