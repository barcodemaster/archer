# 12. Achievement System (업적 시스템)

## 개요
플레이어에게 도전 목표를 제공하는 업적 시스템. 몬스터 처치, 스테이지 클리어, 레벨 달성 등 다양한 조건으로 업적이 해금되며, 보상(골드)이 지급된다.

## 아키텍처

### 데이터 레이어
- **`AchievementTable.cs`**: CSV 행 모델 (id, name, type, target, reward 등)
- **`AchievementDatabase.cs`**: 정적 CSV 파싱. `EquipmentDatabase`와 동일 패턴
- **`AchievementData.csv`**: 15개 업적 데이터 정의

### 핵심 로직
- **`AchievementManager.cs`**: `Singleton<T>` 기반 매니저
  - `AddProgress(type, amount)`: 누적형 (KillCount, GoldEarned 등)
  - `SetProgress(type, value)`: 도달형 (StageClear, LevelReached)
  - `CheckUnlocks()`: 진행도 변경 시 해당 타입 업적 일괄 체크
  - `Unlock()`: 보상 지급 + `OnAchievementUnlocked` 이벤트 발행

### Observer 패턴 (이벤트 Hook)
기존 매니저에 1줄씩 추가하여 업적 진행도를 기록:

| 매니저 | Hook 위치 | 업적 타입 |
|--------|-----------|-----------|
| `StageManager.OnMonsterDead()` | 몬스터 사망 시 | KillCount, BossKill |
| `StageManager.OpenExitDoorSequence()` | 스테이지 클리어 시 | StageClear |
| `ExpManager.AddExp()` | 레벨업 시 | LevelReached |
| `GoldManager.AddGold()` | 골드 획득 시 | GoldEarned |
| `EquipmentManager.AddItem()` | 장비 획득 시 | EquipmentCollected |
| `UI_LevelUp.OnSlotSelected()` | 업그레이드 선택 시 | UpgradeSelected |

### UI
- **`UI_AchievementPopup.cs`**: 토스트 팝업 (Queue 기반, TimeScale 무시)
- **`UI_AchievementPanel.cs`**: 업적 목록 (ScrollRect, 진행바, 해금 표시)

### 저장
- `SaveManager`에 `AchievementSaveData` 통합 (version 1 -> 2 마이그레이션)
- `Dictionary<EAchievementType, int>` 진행도 + `HashSet<int>` 해금 ID

## 디자인 패턴
- **Observer Pattern**: `OnAchievementUnlocked` 이벤트로 UI와 느슨한 결합
- **Singleton Pattern**: `AchievementManager`
- **Data-Driven**: CSV 기반 업적 테이블 (코드 수정 없이 업적 추가 가능)
