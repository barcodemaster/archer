# 00. 프로젝트 개요

## 프로젝트 소개

**Archer Roguelike**는 Unity C#으로 개발된 탑다운 아처 로그라이크 게임입니다.

| 항목 | 내용 |
|------|------|
| 장르 | 탑다운 로그라이크 슈터 |
| 플랫폼 | 모바일 (Android/iOS) |
| 엔진 | Unity (URP) |
| 언어 | C# |
| 입력 | 가상 조이스틱 (터치) |

### 핵심 게임플레이 루프

```
스테이지 진입 → 몬스터 전투 → 경험치/골드/장비 획득
                     ↓
              레벨업 → 업그레이드 선택
                     ↓
              몬스터 전멸 → 드롭 아이템 자동 수집
                     ↓
              출구 문 개방 → 다음 스테이지로 이동
```

플레이어는 조이스틱으로 이동하며, 정지 시 가장 가까운 몬스터를 자동으로 공격합니다. 레벨업마다 22개의 업그레이드 중 3개를 룰렛 연출과 함께 제안받고, 하나를 선택하여 캐릭터를 강화합니다. 장비 시스템을 통해 무기/방어구를 장착하고 골드로 강화할 수 있습니다.

## 핵심 디자인 패턴 요약

| 패턴 | 적용 위치 | 설명 | 선택 근거 |
|------|----------|------|----------|
| **Singleton** | GameManager, StageManager 등 7개 매니저 | `Singleton<T>` 제네릭 베이스로 DontDestroyOnLoad 자동 적용 | Lazy Init으로 초기화 순서 관리 불필요, 씬 배치/프리팹 방식 대비 의존성 최소 |
| **State Machine** | PlayerController, MonsterBase | `EState` 열거형 기반 상태 전환, 애니메이션 동기화 | setter에서 애니메이션 자동 전환하여 상태-애니메이션 불일치 버그 구조적 방지 |
| **Template Method** | MonsterBase → 8+ 변종 | `Start()`, `Update()`, `OnDie()` 등 가상 메서드 오버라이드 | 공통 로직 중복 제거 + 변종별 커스텀 자유도, 새 몬스터 추가 시 최소 코드 |
| **Object Pool** | ProjectileBase, DamageText, FireExplosion | Queue 기반 풀링 + 60초 미사용 자동 정리 | 매 공격마다 수십 개 생성/파괴 시 GC 스파이크 방지, 유휴 시 메모리 자동 회수 |
| **Observer** | EquipmentManager, ExpManager, GoldManager | C# event/Action으로 UI 갱신 알림 | Manager↔UI 결합도 제거, 새 구독자 추가 시 매니저 코드 수정 불필요 |
| **Data-Driven** | UpgradeDatabase, EquipmentDatabase | CSV 파일에서 런타임 파싱 | 기획자가 Excel로 밸런스 조정 가능, 코드 변경 없이 데이터만 교체 |
| **Strategy** | ProjectileBase (3가지 MoveType) | Straight/Arc/Piercing 이동 전략을 Inspector에서 선택 | 투사체 타입별 클래스 분리 시 풀링 복잡도 증가, 단일 클래스로 통합 관리 |

## 게임 플로우 다이어그램

```
[앱 시작]
    │
    ▼
StageManager.Start()
    ├── SaveManager.Load()         ← JSON에서 장비/골드 복원
    ├── SpawnPlayer()              ← 플레이어 프리팹 생성
    └── StartStage(0)             ← 첫 번째 스테이지 로드
         ├── TileMap.GenerateVisuals()  ← 타일/블록/경계벽 생성
         ├── 몬스터 스폰 (TileMap.PlacedMonsters)
         └── TeleportPlayerToSpawn()
              │
              ▼
        [게임 루프]
         ├── 이동: 조이스틱 → GameManager.JoystickDir → PlayerController.Update()
         ├── 전투: 정지 시 FindClosestMonster() → 자동 공격
         ├── 피격: MonsterBase.TakeDamage() → DamageText, CameraShake
         │
         ├── 몬스터 사망: StageManager.OnMonsterDead()
         │    ├── ExpOrb, GoldOrb, HPHeart, EquipmentOrb 드롭
         │    └── BloodThirst HP 회복
         │
         ├── 레벨업: ExpManager → UI_LevelUp (룰렛) → PlayerUpgrade.AddUpgrade()
         │
         └── 전멸 시:
              ├── 드롭 아이템 자동 수집 (플레이어에게 비행)
              ├── ExitDoor 개방 (빛 + 파티클 이펙트)
              └── 플레이어 진입 → StageManager.GoToNextStage()
                   ├── FadeOut → StartStage(next) → FadeIn
                   └── [게임 루프] 반복
```
