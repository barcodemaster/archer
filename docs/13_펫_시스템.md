# 13. Pet System (펫 시스템)

## 개요
플레이어를 따라다니며 자율적으로 전투하는 동반자 시스템. 장비 슬롯(Pet1/Pet2)에 장착하면 펫이 스폰되며, FSM 기반으로 Patrol/Return/Chase/Attack 행동을 수행한다.

## 설계 원칙
- 펫은 플레이어 offset **주변을 Patrol** (offset 스냅 X, 자율 이동)
- 플레이어와 거리가 멀어지면 offset 위치로 **Return** (이동 중 목적지 재계산 X)
- 적 감지 시 **Chase** → 사거리 도달 시 **Attack**
- HP 없음, 발사체 기반 공격, Idle/Move/Attack 애니메이션
- 기존 장비 시스템과 완전 통합 (장착/해제로 스폰/디스폰)

## 상태 전이 다이어그램

```
           [Patrol] ──(enemy detected)──> [Chase]
             │  ^                           │  ^
  (too far)  │  │ (arrived)      (in range) │  │ (out of range)
             v  │                           v  │
          [Return]                       [Attack]
             ^                              │
             └──────(too far after attack)──┘
```

## 아키텍처

### 컴포넌트 구조
```
PlayerController (GameObject)
  └── PetSpawner.cs         ← EquipmentManager.OnEquipChanged 구독
        ├── PetController(Pet1)  ← FSM 호스트, 동적 스폰
        └── PetController(Pet2)  ← FSM 호스트, 동적 스폰
```

### FSM 구조
```
IPetState (인터페이스)
  ├── PetPatrolState   ← offset 주변 랜덤 순찰
  ├── PetReturnState   ← 잠긴 offset 위치로 복귀
  ├── PetChaseState    ← 타겟 몬스터 추적
  └── PetAttackState   ← 발사체 발사 + 쿨다운
```

모든 상태는 `public static readonly Instance` 싱글턴 패턴 (IMonsterState와 동일).

### PetController.cs — FSM 호스트
상태가 사용하는 공유 데이터와 헬퍼 메서드를 노출:

**공유 데이터:**
- `LockedReturnTarget` — Return 시 잠긴 목적지
- `ChaseTarget` — 추적 중인 몬스터
- `PatrolTarget`, `HasPatrolTarget` — 순찰 지점
- `StateTimer`, `AttackTimer`, `PatrolWaitTimer` — 타이머

**헬퍼 메서드:**
- `TransitionTo(IPetState)` — 상태 전환 (Exit → Enter)
- `MoveTo(Vector3, float)` — MoveTowards 이동 + 방향 회전
- `FaceDirection(Vector3)` — 타겟 방향 회전
- `FireProjectile()` — Arc/Straight 발사체 생성 (ProjectileFactory)
- `FindNearestMonster(float)` — AliveMonsters에서 범위 내 최근접 탐색
- `PlayAnimation(int)` — CrossFade 애니메이션 재생
- `OffsetPosition` (프로퍼티) — 플레이어 기준 offset 월드 좌표
- `DistanceToPlayer` (프로퍼티) — 플레이어와의 거리

**Update:** `_currentState?.Update(this)` 한 줄

### 상태별 동작

#### PetPatrolState
1. offset 위치 기준 `petPatrolRadius` 내 랜덤 지점으로 이동
2. 도착 시 `petPatrolWaitTime` 대기 후 다음 지점 선택
3. 플레이어 거리 > `petReturnThreshold` → ReturnState
4. `petDetectionRange` 내 몬스터 발견 → ChaseState

#### PetReturnState
1. Enter 시 현재 offset 위치를 `LockedReturnTarget`에 잠금 (이후 재계산 X)
2. `petReturnSpeed`로 잠긴 위치까지 이동
3. 도착(< 0.2f) → PatrolState

#### PetChaseState
1. 타겟 사망/null → PatrolState
2. 타겟 거리 ≤ `petAttackRange` → AttackState
3. `petChaseSpeed`로 타겟 방향 이동
4. chase 시간 > `petChaseTimeout` → PatrolState (포기)
5. 플레이어 거리 > `petReturnThreshold` → ReturnState

#### PetAttackState
1. Enter 시 즉시 `FireProjectile()` 호출
2. 쿨다운(`petAttackCooldown`) 대기
3. 쿨다운 후 판단:
   - 플레이어 거리 > `petReturnThreshold` → ReturnState
   - 타겟 사망 → PatrolState
   - 사거리 내 → 재공격 (유지)
   - 사거리 밖 → ChaseState

### PetSpawner.cs
- `EquipmentManager.OnEquipChanged` 이벤트 구독
- Pet1/Pet2 슬롯 상태 변경 시 자동 스폰/디스폰
- 디스폰 시 `TransitionTo(null)` 호출하여 현재 상태 Exit 실행
- 같은 장비의 레벨업 시 `RefreshStats()`만 호출 (재스폰 없음)

## 밸런스 (GameConfig)

### 기본 설정
| 설정 | 기본값 | 설명 |
|------|--------|------|
| petOffset1 | (-0.8, 0, -0.5) | Pet1 로컬 좌표 오프셋 |
| petOffset2 | (0.8, 0, -0.5) | Pet2 로컬 좌표 오프셋 |
| petAttackCooldown | 1.5초 | 공격 쿨다운 |
| petScale | 0.5 | 펫 스케일 |

| 설정 | 기본값 | 설명 |
|------|--------|------|
| petPatrolRadius | 1.0 | Patrol 랜덤 이동 반경 |
| petPatrolSpeed | 1.5 | Patrol 이동 속도 |
| petPatrolWaitTime | 0.8초 | Patrol 도착 후 대기 시간 |
| petReturnThreshold | 6.0 | Return 트리거 거리 |
| petReturnSpeed | 5.0 | Return 이동 속도 |
| petChaseSpeed | 3.5 | Chase 이동 속도 |
| petDetectionRange | 5.0 | 적 감지 범위 |
| petAttackRange | 2.5 | 공격 사거리 |
| petChaseTimeout | 4.0초 | Chase 포기 시간 |

## 기존 시스템 재사용
- `EquipmentManager.OnEquipChanged`: 스폰 트리거
- `EquipmentData.GetMainStat()`: 데미지 계산
- `ProjectileFactory.Create()` / `CreateArc()`: 펫 투사체 생성
- `StageManager.AliveMonsters`: 타겟 탐색
- `GameConfig.Instance`: 밸런스 값 중앙 관리

## 디자인 패턴
- **State Pattern**: `IPetState` + 4개 상태 클래스 (FSM 기반 자율 행동)
- **Observer Pattern**: `OnEquipChanged` 이벤트로 스폰 트리거
- **Factory Pattern**: `ProjectileFactory`로 모든 펫 투사체 생성 (Arc/Straight 통합)
- **Singleton (상태)**: 각 상태 클래스에 `static readonly Instance` (GC 부하 제거)
- **Component Pattern**: Player에 `PetSpawner` 부착, 동적 `PetController` 생성
